This is a Command-Line Interface (CLI) based system built in C++ to manage airline bookings. It was developed as a semester project to demonstrate the practical application of Data Structures.

Key Features
Admin Login: Secure access using a username and password with built-in error handling.

Flight Search: Uses a Binary Search Tree (BST) to find flight details quickly.

Booking System: Manages passenger information dynamically using Linked Lists.

Waitlist Management: Automatically moves passengers to a Queue if a flight reaches full capacity.

Cancellation & Undo: Uses a Stack to track cancelled tickets, allowing for efficient record management.

Data Persistence: Saves all passenger and flight records to a text file (Database.txt) so data is not lost when the program closes.

Data Structures Used
BST: For efficient flight lookups.

Linked List: For dynamic passenger data storage.

Stack: To handle undo/log operations for cancellations.

Queue: To manage the passenger waitlist (First-In, First-Out).
